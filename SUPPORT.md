# Support

Use GitHub issues for reproducible bugs and focused feature requests. Include
the commit or version, Node version, browser, deployment mode, Region, and a
sanitized reproduction. Do not include credentials, prompts containing private
data, customer infrastructure, or production logs.

Security issues belong in GitHub private vulnerability reporting as described
in `SECURITY.md`.

AxonLLM Blueprint is a beta reference implementation. Maintainers do not
provide an SLA, production operations, account access, model enablement, or
deployment approval.
