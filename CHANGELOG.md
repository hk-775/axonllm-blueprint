# Changelog

All notable changes are documented in this file.

## 0.1.0-beta.1 - 2026-08-29

- Introduced the AxonLLM Blueprint product identity and workbench UI.
- Added Bedrock Converse integration with adaptive retries.
- Added architecture, IaC generation, configuration review, and troubleshooting workflows.
- Added bounded in-memory sessions and request limits.
- Added server-side model allowlisting and safer error responses.
- Added Docker packaging, CI, CodeQL, open-source governance files, and architecture assets.
- Added trusted-proxy identity enforcement, tenant-bound sessions, and per-principal rate limiting.
- Added CSP, HSTS, no-store API responses, and a production access-mode startup guard.
- Pinned CI actions and the Node container base to immutable commits and digests.
- Added dependency signature checks, CycloneDX SBOM generation, and container vulnerability scanning.
